# 課題の紹介

- このサイトは、自分自身を紹介するためのプロフィールサイトとして制作しました。
- 僕は自然や生き物が好きなので、サイト全体を通して自然を感じられるようなデザインを意識しています。
- 緑を中心とした落ち着いた配色や、やわらかい雰囲気のレイアウトを取り入れ、見やすく親しみやすいサイトになるように制作しました。

## TOP

- TOPページのこだわりポイントはスライド式で動く画像とページ案内から選んだページに飛べる機能です。
- デザインは自然をイメージしてChat GPTに作ってもらいました。

## About

- このページは自己紹介をするページです。
- 名前や専攻、自己紹介、将来の目標などを項目ごとに分けて表示し、情報が一か所にまとまりすぎないようにしました。

## Contact

- このページでは、フォームのデザインをどのようにすればサイト全体の雰囲気に合うのか特に悩みました。

##　Skills

- Skillsページでは、自分が学んでいることや使用できる技術について紹介しています。
- 単純にスキル名だけを並べるのではなく、それぞれを見やすく整理して表示することを意識しました。

## Favorite

- Favoriteページでは、自分の好きなものについて紹介しています。
- このサイトでは自然や生き物をテーマにしているため、自分の好きなものを紹介するページもサイト全体の雰囲気と合うように意識しました。
- 文章だけではなく、画像やカードなどを使うことで、見る人が直感的に内容を理解できるようなページを目指しています。


# 一番見てほしいところ

- 一番見てほしいところは、サイト全体の統一感です。
- TOP、About、Skills、Favorite、Contactの5ページがありますが、それぞれ別々のデザインにするのではなく、緑を中心とした配色やカードの形、文字の雰囲気などを統一しています。
- 特にTOPページのスライド画像やページ案内は、サイトに入って最初に目にする部分なので見てほしいポイントです。
- 自然をイメージしたデザインが各ページに共通して使われているところにも注目してほしいです。

# 力を入れた点

- 実装面では、複数のページを作成し、それぞれを正しく移動できるようにした点に力を入れました。
- ヘッダーのナビゲーションだけでなく、TOPページのページ案内からも各ページへ移動できるようにしています。

## 実装面

- 実装面では、複数のページを作成し、それぞれを正しく移動できるようにした点に力を入れました。
- ヘッダーのナビゲーションだけでなく、TOPページのページ案内からも各ページへ移動できるようにしています。
- 特に、複数の要素を横並びにしたときの幅や余白の調整、ページごとのレイアウトを揃える部分が難しかったです。

## デザイン面

- デザイン面では、「自然」をサイト全体のテーマとして統一したことに力を入れました。
- 緑や白を中心とした落ち着いた色を使用し、自然や生き物が好きという自分の特徴がサイトを見ただけでも少し伝わるようにしています。
- デザインを形にする上で難しかったのは、見た目を良くすることと情報を分かりやすくすることの両立です。
