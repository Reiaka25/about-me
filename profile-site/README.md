# Profile Site

## サイト概要

自分自身のプロフィールサイトとして使える、5ページ構成の静的Webサイトです。サイト内の情報はあとから編集する想定で、具体的な個人情報は入れず、仮テキストで作成しています。

## ページ構成

- `index.html`: TOPページ。短い自己紹介、各ページへの導線、画像スライダーを配置しています。
- `about.html`: Aboutページ。名前、所属・専攻、自己紹介文、将来の目標、強みを編集しやすい形で配置しています。
- `skills.html`: Skillsページ。スキル名、説明、習熟度をカード形式で配置しています。
- `favorite.html`: Favoriteページ。好きなものをカード形式で配置しています。
- `contact.html`: Contactページ。入力チェック付きのお問い合わせフォームを配置しています。

## 使用技術

- HTML
- CSS
- JavaScript
- 自作SVG画像

## 実装したJavaScript機能

- ハンバーガーメニュー
- TOPページの画像スライダー
- Contactページのフォーム入力チェック
- ページ上部へ戻るボタン
- スクロール時のフェードイン表示

## デザインの工夫

自然をイメージした緑系の配色で統一し、落ち着いた雰囲気にしています。カード、ボタン、フォームのデザインを共通化し、あとから文章を差し替えても見た目が崩れにくい構成にしています。メディアクエリを使い、スマートフォンでも読みやすいレイアウトに調整しています。

## 著作権について

画像はすべて自作SVGを使用しています。文章は汎用的な仮テキストで作成しており、実在する個人名、学校名、メールアドレス、作品名、企業名などは記載していません。

## 生成AIによるコードレビュー

提出前に、生成AIによるコードレビュー観点で、ファイル構成、必須要件、JavaScript機能、レスポンシブ対応、個人情報の扱いを確認しています。

## お問い合わせフォームについて

お問い合わせフォームには送信機能がありません。JavaScriptによる入力チェックのみを実装しています。

## 編集について

サイト内の情報はあとから編集する想定です。表示名、所属、スキル、好きなもの、メールアドレスなどは、公開前に内容を確認してから差し替えてください。
